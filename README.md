Nhóm 9 môn bigdata 
1.  Tải dữ liệu đầu vào (VN_housing_dataset.csv).
2.  Mở `dataclean.ipynb` để thực hiện làm sạch dữ liệu.
3.  Kết quả sau khi làm sạch sẽ được lưu thành file `housing_data_cleaned_v3.csv`.
4.  Đưa dữ liệu lên HDFS 
5.  upload file đã làm sạch lên HDFS và run 'spark-submit train_moel.py'
